# screw-scissor-lift-mechanism-Solidworks
3D CAD assembly of a Two-Stage Screw Scissor Lift Mechanism in SolidWorks (MMGS). Includes 6 unique native .SLDPRT parts (25 total instances) with slotted platforms, dual X-stage scissor arms, chrome trunnion cross-bars, lead screw with handwheel, and kinematic mates.
